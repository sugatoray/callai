# How-to guides

Task-focused recipes. Each one stands alone, so read them in any order. They assume you know the basics
from the [Tutorial](../tutorial/README.md).

- [Call callai from an AI agent](use-from-an-ai-agent.md): run harnesses as sub-agents safely and parse what comes back.
- [Use callai in scripts and CI](scripts-and-ci.md): stdin, timeouts, exit codes and JSON in shell pipelines.
- [Compare harnesses side by side](compare-harnesses.md): one prompt, every harness, a model alias each.
- [Build a live progress view](live-progress.md): turn stream events into a progress display.
- [Test without a real model](test-without-a-model.md): fake harnesses for your tests, and real harnesses against a stub model.
- [Add a new harness](add-a-harness.md): write an adapter and prove it with the conformance suite.
